Pengenalan HTML dan Struktur Web

Materi pertama ini akan membahas bagaimana cara membangun fondasi dari sebuah halaman web menggunakan tag-tag dasar HTML5.

Ringkasan Materi

Poin Penting:

1. HTML (HyperText Markup Language) adalah tulang punggung dari semua halaman website.
2. Tag wajib seperti <html>, <head>, dan <body> harus selalu ada.
3. Bagian <head> digunakan untuk metadata, pengaturan font, CSS, dan judul tab browser.
4. Semua konten yang dilihat pengguna (teks, gambar, video) ditulis di dalam tag <body>.
5. Selalu gunakan Semantic HTML (seperti <header>, <main>, <footer>) untuk aksesibilitas dan SEO yang baik.
